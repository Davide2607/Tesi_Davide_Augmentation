# Davide_Augmentation_Thesis

PoliTO thesis project focused on improving facial expression recognition accuracy through data augmentation techniques.

Author: Davide Ravida

## Repository structure

The project is organized into folders that separate documentation, synthetic data generation, model training, and scripts for execution on an HPC cluster:

- `README.md`: general project description and basic instructions.
- `docs/`: supporting files and project dependencies; `requiriments.txt` lists the required Python packages.
- `scripts/`: reusable Python modules for the complete pipeline. In particular:
  - `loading_data.py` loads and prepares datasets, including HDF5 files;
  - `data_generators.py` contains data generators and augmentation procedures;
  - `backbone.py` defines the available CNN backbones, including ResNet, VGG, EfficientNet, Inception, MobileNet, and ConvNeXt;
  - `finetuning.py`, `train_final_layers.py`, and the `optimizer_*.py` scripts handle fine-tuning, training, and classifier optimization;
  - `losses.py` collects loss functions, while the `inspect_*`, `compare_*`, `summarize_*`, and `visualize_*` scripts are used for checks, analysis, and result visualization;
  - `merge_*`, `export_*`, `extract_*`, `filter_*`, and `pack_*` manage dataset and generated-image conversion, filtering, and merging.
- `neaural_networks/`: code and notebooks dedicated to the generative networks used for augmentation. `WGAN_GP_DATA_AUGMENTATION.py` implements a conditional WGAN-GP for rare classes, while `StyleGAN2_ADA_FER.py` automates dataset preparation, training, and image generation with StyleGAN2-ADA. The folder also contains notebooks for CGAN, WGAN-GP, and StyleGAN2.
- `sbatch/`: SLURM jobs for launching training, fine-tuning, dataset preparation, and image generation on the cluster.
- `sbatch_meta/`: jobs for environment setup and CPU/GPU execution templates.
- `Immagini/`: examples and grids of synthetic images generated by the GANs, useful for qualitative inspection of the results.
- `CONFIDENCE_MODEL.ipynb`: notebook for analyzing model confidence.

Overall, the notebooks and scripts in `neaural_networks/` generate synthetic images; the tools in `scripts/` integrate them into the datasets and train the classifiers; finally, the files in `sbatch/` automate the same steps on the cluster.
